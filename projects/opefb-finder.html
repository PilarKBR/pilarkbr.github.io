OPEFB-Finder

Python application for detecting the presence of oil palm empty fruit bunch piles using a modified Excess Green Index (ExG) method.

Project Overview

OPEFB-Finder is a specialized Python application developed to address a significant challenge in palm oil production: detecting and locating Oil Palm Empty Fruit Bunch (OPEFB) piles in plantation areas. By implementing a modified Excess Green Index (ExG) algorithm, the application can identify these waste materials with high accuracy from aerial imagery.

Key Features

  • Modified ExG Algorithm: Custom implementation of the Excess Green Index with specific optimizations for OPEFB detection
  • Image Pre-processing: Advanced filters and transformations to enhance detection accuracy
  • Geolocation Mapping: Integration with GPS data to precisely locate detected OPEFB piles
  • User-friendly Interface: Simple yet powerful interface for agricultural technicians
  • Batch Processing: Ability to process multiple images in a single operation

Technical Implementation

Modified Excess Green Index (ExG)

The standard ExG is calculated as:

ExG = 2 * G - R - B

Where G, R, and B are the green, red, and blue channels of the image. Our modified approach includes:

ModifiedExG = 2.5 * G - 1.3 * R - 0.7 * B

This modification provides better sensitivity to the specific color profile of OPEFB piles in various lighting conditions.

Image Processing Pipeline

  1. Image Acquisition: Loading and normalizing aerial images
  2. Pre-processing: Noise reduction and contrast enhancement
  3. ExG Calculation: Application of our modified ExG algorithm
  4. Thresholding: Conversion to binary image using adaptive thresholding
  5. Morphological Operations: Erosion and dilation to refine detected regions
  6. Contour Detection: Identifying and marking OPEFB pile boundaries
  7. Result Visualization: Highlighting detected areas on the original image

Example Code Snippet

import cv2
import numpy as np

def calculate_modified_exg(image):
    # Split the image into its BGR components
    b, g, r = cv2.split(image)
    
    # Convert to float for calculation
    b = b.astype(float)
    g = g.astype(float)
    r = r.astype(float)
    
    # Calculate modified ExG
    modified_exg = 2.5 * g - 1.3 * r - 0.7 * b
    
    # Normalize to 0-255 range
    modified_exg = cv2.normalize(modified_exg, None, 0, 255, cv2.NORM_MINMAX)
    modified_exg = np.uint8(modified_exg)
    
    return modified_exg

def detect_opefb(image_path):
    # Load the image
    image = cv2.imread(image_path)
    
    # Calculate modified ExG
    exg = calculate_modified_exg(image)
    
    # Apply threshold
    _, binary = cv2.threshold(exg, 0, 255, cv2.THRESH_BINARY + cv2.THRESH_OTSU)
    
    # Apply morphological operations
    kernel = np.ones((5,5), np.uint8)
    binary = cv2.morphologyEx(binary, cv2.MORPH_OPEN, kernel)
    binary = cv2.morphologyEx(binary, cv2.MORPH_CLOSE, kernel)
    
    # Find contours
    contours, _ = cv2.findContours(binary, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)
    
    # Draw contours on original image
    result = image.copy()
    cv2.drawContours(result, contours, -1, (0, 255, 0), 2)
    
    return result, exg, binary

Results and Impact

The OPEFB-Finder has been successfully deployed in several palm oil plantations in Indonesia, with remarkable results:
