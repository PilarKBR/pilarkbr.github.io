OPEFB-Detection-System

Automated spatial detection system for Oil Palm Empty Fruit Bunch (OPEFB) waste using modified Excess Green Index and DBSCAN clustering algorithm based on drone RGB imagery.

Abstract & Background

The management of Oil Palm Empty Fruit Bunch (OPEFB) waste remains a significant challenge in oil palm plantations, particularly in Desa Wirajaya, Jasinga District, Bogor Regency, due to limited access and reliance on manual record-keeping systems. This research developed an automated system to accurately detect and map OPEFB pile locations based on drone RGB aerial imagery and spatial analysis. The system employs a modified Excess Green Index (ExG) algorithm combined with DBSCAN clustering to identify OPEFB locations across plantation areas.

Research Location & Context

Field research was conducted at oil palm plantations in Desa Wirajaya, Kecamatan Jasinga, Kabupaten Bogor, covering areas with significant OPEFB accumulation. The plantation faces challenges in systematic waste management due to terrain accessibility and lack of efficient monitoring systems. This research addresses these challenges through technology-driven spatial detection methodology.

Research Methodology

The detection system development followed a structured flowchart encompassing: (1) Aerial Image Acquisition using DJI Phantom 4 Pro V2.0 drone with vertical (nadir) positioning at 1/800 shutter speed and ISO 400 settings, (2) Image Preprocessing including HSV color space conversion and V-channel normalization using cv2.cvtColor() and Pallet (V) functions, (3) Color Segmentation via modified Excess Green Index (ExG = 2.4375 × G - (R + B)), (4) Image Extraction through filtering and binary conversion, (5) DBSCAN Spatial Analysis comparing Euclidean and Haversine distance metrics, and (6) Evaluation using precision and recall metrics with ground truth validation.

Algorithm Innovation - Modified ExG:

The research introduces a modified Excess Green Index formula optimized for OPEFB detection:

Standard ExG: ExG = 2G - R - B Modified ExG: ExG = 2.4375 × G - (R + B)

Where G (Green Channel), R (Red Channel), and B (Blue Channel) are extracted from RGB aerial imagery. The coefficient 2.4375 was empirically determined through extensive testing to maximize sensitivity to OPEFB color characteristics under tropical lighting conditions with varying shadows and canopy coverage.

Detection Accuracy Metrics

The system was evaluated using precision and recall metrics comparing two spatial clustering approaches:

Spatial Clustering Methods Comparison:

Euclidean Distance Method

Precision: 0.1043 (10.43%)

Recall: 0.2124 (21.24%)

Pixel-based distance calculation within image coordinate system

Haversine Distance Method ⭐

Precision: 0.2174 (21.74%)

Key Finding: The Haversine distance method demonstrated significantly better performance with 21.74% precision and 50.81% recall compared to Euclidean's 10.43% precision and 21.24% recall. This indicates that geographic coordinate-based spatial clustering is more accurate for real-world OPEFB detection in field conditions.

Technical Implementation

Image Preprocessing Pipeline

The initial stage converts RGB drone imagery to HSV color space for robust segmentation:

  1. Color Space Conversion: RGB to HSV using cv2.cvtColor() function for enhanced color channel separation
  2. V-Channel Normalization: Value channel extraction and normalization to [0, 1] range for consistent lighting conditions
  3. Pallet Function Application: Color enhancement through Hue (H) and Saturation (S) channel manipulation
  4. Channel Reintegration: Normalized V-channel merged back for optimal ExG segmentation

Modified Excess Green Index (ExG) Algorithm

The core innovation for color-based OPEFB segmentation:

ExG = 2.4375 × G - (R + B)

Where G (Green), R (Red), and B (Blue) are RGB channel values. The coefficient 2.4375 maximizes non-vegetative object dominance (brownish OPEFB) while minimizing green canopy interference. This threshold-based approach effectively separates OPEFB piles from oil palm foliage under tropical lighting with varying shadows.

Image Extraction & Binary Conversion

Post-ExG processing for spatial object representation:

  • Thresholding: Binary image generation separating OPEFB (foreground) from background using adaptive thresholding techniques
  • Morphological Filtering: Noise removal and small irrelevant object elimination through erosion and dilation operations
  • Edge Detection (Canny): Contour boundary delineation using Canny edge detection algorithm for precise object border identification
  • Non-local Means Filtering: Denoising while preserving OPEFB pile edge structures and geometric integrity

Contour Extraction & Spatial Clustering

The system identifies and groups detected OPEFB regions using advanced spatial analysis:

  1. Outer Contour Extraction: Detection of object boundaries from binary segmentation results
  2. Centroid Calculation: Geometric center point determination for each detected OPEFB cluster
  3. GPS Coordinate Conversion: Transformation from pixel coordinates to WGS84 geographic coordinates using embedded GNSS metadata
  4. DBSCAN Clustering: Density-based spatial grouping to merge nearby detections and form meaningful OPEFB pile clusters
  5. Convex Hull Formation: Cluster boundary polygon generation for area calculation and spatial representation

DBSCAN Algorithm Configuration

Density-Based Spatial Clustering of Applications with Noise (DBSCAN) parameters for OPEFB pile grouping. The system uses Haversine distance metric for GPS coordinate-based geographic distance calculation (WGS84 ellipsoid model), which demonstrated superior performance compared to pixel-based Euclidean distance (see Results section for detailed comparison).

Ground Sampling Distance (GSD) Calculation

Critical for converting pixel measurements to real-world metric distances:

GSDh = (H × s) / (f × lv) GSDv = (H × s) / (f × lh)

Where:

  • H = Drone altitude (40 meters)
  • s = Camera sensor width/height (13.2mm × 8.8mm)
  • f = Focal length of camera lens
  • lv = Vertical image resolution (3648 pixels)
  • lh = Horizontal image resolution (4864 pixels)

Calculated GSD Values: GSDh ≈ 0.0123 m/px and GSDv ≈ 0.0109 m/px, enabling precise spatial measurements and area calculations for detected OPEFB clusters.

Research Conclusions & Impact

Summary of Key Findings

The research successfully demonstrates an automated OPEFB detection system combining modified ExG algorithm (coefficient 2.4375) with DBSCAN spatial clustering, achieving significant improvements over manual detection methods. The Haversine distance-based approach achieved 21.74% precision and 50.81% recall, significantly outperforming pixel-based Euclidean methods (10.43% precision, 21.24% recall).

Practical Implementation Benefits

The system provides tangible operational improvements for plantation management:

  • Field Navigation: GPS coordinates enable farming groups to locate OPEFB piles efficiently, reducing search time and improving collection logistics
  • Resource Optimization: Targeted waste collection reduces fuel consumption and operational costs compared to manual area-wide inspections
  • Environmental Management: Improved OPEFB tracking supports sustainable practices including strategic mulching and composting operations
  • Decision Support: GIS-compatible outputs (QGIS, Google Earth) enable data-driven plantation management and waste cleanup planning
  • Temporal Monitoring: Regular aerial surveys enable tracking of OPEFB accumulation patterns over time for proactive waste management
