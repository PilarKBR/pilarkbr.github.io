OPEFB-Finder

Python application for detecting the presence of oil palm empty fruit bunch piles using a modified Excess Green Index (ExG) method.

Project Overview

OPEFB-Finder is a specialized Python application developed to address a significant challenge in palm oil production: detecting and locating Oil Palm Empty Fruit Bunch (OPEFB) piles in plantation areas. By implementing a modified Excess Green Index (ExG) algorithm, the application can identify these waste materials with high accuracy from aerial imagery.

Technical Implementation

Modified Excess Green Index (ExG)

The standard ExG is calculated as:

ExG = 2 * G - R - B

Where G, R, and B are the green, red, and blue channels of the image. Our modified approach includes:

ModifiedExG = 2.4375 * G - (R + B)

This modification provides better sensitivity to the specific color profile of OPEFB piles in various lighting conditions.

Image Processing Pipeline

  1. Image Acquisition: Loading and normalizing aerial images
  2. Pre-processing: Noise reduction and contrast enhancement
  3. ExG Calculation: Application of our modified ExG algorithm
  4. Thresholding: Conversion to binary image using adaptive thresholding
  5. Morphological Operations: Erosion and dilation to refine detected regions
  6. Contour Detection: Identifying and marking OPEFB pile boundaries
  7. Result Visualization: Highlighting detected areas on the original image
